Before You Print

Getting a Clean Print

A couple of settings worth checking so the staves come out evenly spaced and the lines stay crisp.

  • 📐
    Print at 100% — don't "fit to page" Scaling squashes the string spacing and makes the sheets awkward to write on. Turn off any auto-fit or shrink-to-fit option in your print dialog.
  • 🖨️
    Grayscale is fine These are plain black lines, so there's no need to burn color ink. Draft quality prints perfectly well and saves toner.
  • ✏️
    Print a stack, write in pencil Fingerings change as you work a part out. Pencil lets you keep revising the same sheet instead of starting over.
